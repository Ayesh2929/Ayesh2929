01 / THE MODEL

What the projection
is actually showing.

A tesseract is the four-dimensional analogue of a cube. A 2D screen cannot display four spatial axes directly, so the lab rotates the coordinates in 4D, projects them into 3D, then applies a camera projection.

HYPERCUBE TOPOLOGY{−1, +1}⁴

Four coordinates, each at −1 or +1: 16 vertices. Join two vertices when exactly one coordinate differs: 32 edges.

ROTATION PLANESXY · ZW · XW · YZ

Independent 4D rotations change how the inner and outer cube-like slices weave through the projection.

4D PERSPECTIVEscale₄ = d / (d − w)

The fourth coordinate controls perspective before the model reaches ordinary three-dimensional space.

CAMERA PROJECTIONscale₃ = f / (f − z)

A final perspective step maps the projected 3D vertices onto the canvas and gives the wireframe depth cues.

02 / INTERACTION MODEL

Built for curiosity,
not just spectacle.

The controls keep the geometry inspectable: you can pause, change one rotation plane at a time, adjust the perspective distance, and return to the initial pose.

Pointer drag

Steers two rotation planes. Canvas uses pointer capture, so dragging works with mouse, pen, or touch.

Keyboard

Focus the model. Arrow keys change the view; Space starts or pauses automatic rotation.

Motion preference

The renderer starts paused when the operating system requests reduced motion.

Browser budget

Canvas pixel density is capped; animation pauses when the tab is hidden or the scene scrolls out of view.

This is a software-rendered projection on a 2D canvas, not a WebGL scene. The STL file is a separate mesh for compatible 3D viewers.
