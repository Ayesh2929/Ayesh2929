01 / WHOAMI

A builder with
multiple workbenches.

I enjoy the connection between a product idea and the systems that make it useful. My public work includes a household-finance web application, a small React Native task interface, and a personal Linux desktop configuration project.

Those projects give me different lenses: data and localization in a web product; state, navigation, and touch interaction on mobile; and repeatable configuration and automation on the desktop.

This archive favors traceable details over status theater. Technologies are tied to repositories; charts explain what they count; incomplete paths are labeled as incomplete.
