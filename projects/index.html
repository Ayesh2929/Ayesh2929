Household finance · English + Sinhala UI

DEPLOYMENT NOTEThe current `auth.js` has a known development fallback when `JWT_SECRET` is unset. Set a high-entropy secret in the deployment environment; do not treat the fallback as production configuration. This is a code observation, not a security certification.
Inspect the data model and route sources
The migrations define users, incomes, expenses, budgets, savings goals, loans, bills, bank accounts, family members, and activity logs. The API uses `user_id` for finance resources and `owner_user_id` for family-scoped records.
